# Claims & Ticket Management System

## Project Overview
This project is a console-based Claims & Ticket Management System developed using Python and SQLite. It simulates real-world service desk and healthcare claims workflows including incident tracking, SLA monitoring, ticket lifecycle management, and workflow coordination.

---

## Features

- Ticket Creation
- Ticket Status Management
- SLA Monitoring
- Incident Tracking
- Ticket Search Functionality
- Ticket Deletion
- Category Management
- SQLite Database Integration
- Colorful Console Interface using Colorama

---

## Technologies Used

- Python
- SQLite
- Colorama

---

## Ticket Workflow

Open → In Progress → Resolved → Closed
